# Telegram Auth Bot

Бот для аутентификации пользователей по номеру телефона с подтверждением администратора для доступа к Telegram группам.

## 🚀 Возможности
- **Аутентификация по номеру телефона** - пользователи проходят верификацию
- **Подтверждение администратора** - владелец группы подтверждает регистрацию пользователей
- **Автоматическое ограничение прав** - новые пользователи не могут писать сообщения до подтверждения
- **Таймаут авторизации** - пользователи удаляются из группы, если не авторизовались в течение 2 минут
- **Мультигрупповая поддержка** - бот работает с несколькими группами одновременно
- **JSON база данных** - все данные хранятся в файлах JSON

## 📋 Требования
- Python 3.8+
- python-telegram-bot 20.0+
- APScheduler (для планировщика задач)

## Настройка
Конфигурация бота (config.py)
```python
BOT_SETTINGS = {
    'auth_timeout': 120,  # 2 минуты в секундах
    'data_directory': 'data',
    'groups_directory': 'data/groups', 
    'users_directory': 'data/users',
    'admin_notification': True,
    'debug': True
}
```
### Права бота в группе
Боту необходимы следующие права в группе:  
✅ Обязательные: Ban users, Delete messages, Restrict members  
✅ Рекомендуемые: Invite users via link  
❌ Не нужны: Change group info, Pin messages

## Разработка
Добавление нового функционала:  
Создайте новый модуль в папке bot/  
Импортируйте и зарегистрируйте обработчики в core.py  
Добавьте необходимые настройки в config.py  
Расширение базы данных:  
Методы для работы с данными находятся в bot/database.py:  
get_group(), save_group() - работа с группами  
get_user(), save_user() - работа с пользователями  
add_pending_user(), approve_user() - управление ожидающими  

## Решение проблем
**Пользователь не получает сообщения:**  
Проверьте, что пользователь начал диалог с ботом  
Убедитесь, что бот не заблокирован пользователем  
**Кнопки не работают:**  
Проверьте ID администратора в my_secrets.py  
Убедитесь, что бот имеет необходимые права в группе  

**Ошибки прав:**  
Дайте боту права администратора в группе  
Убедитесь, что бот может ограничивать пользователей  

**Ошибки базы данных:**  
Проверьте права на запись в папку data/  
Убедитесь, что JSON файлы не повреждены
