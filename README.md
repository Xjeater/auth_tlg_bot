# Telegram Group Approval Bot

Бот для управления доступом к Telegram группам с подтверждением администратора.

## 🚀 Возможности
- **Автоматическое ограничение прав** - новые пользователи не могут писать сообщения до подтверждения
- **Уведомления администратора** - владелец группы получает уведомление о новых пользователях
- **Управление через кнопки** - админ подтверждает или отклоняет доступ одним кликом
- **Мультигрупповая поддержка** - бот работает с несколькими группами одновременно
- **JSON база данных** - все данные хранятся в файлах JSON

## 🛠️ Команды для администраторов
Администраторы (указанные в `ADMIN_IDS`) имеют доступ к специальным командам:
### `/admin_help` 
Показывает справку по командам администратора
### `/admin_status`
Показывает статус всех групп, где работает бот:
- Количество одобренных участников
- Количество пользователей ожидающих одобрения
### `/stats`
Показывает общую статистику системы:
- Общее количество групп
- Количество одобренных пользователей
- Количество ожидающих одобрения
